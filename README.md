💡 Sobre o projeto

O Conecta Mais é uma plataforma digital de impacto social desenvolvida com HTML e CSS, com a proposta de aproximar pessoas, facilitar o acesso à informação e incentivar iniciativas solidárias.

🎯 Objetivo

Utilizar a tecnologia como ferramenta de transformação social, promovendo conexões, compartilhamento de conhecimento e colaboração entre pessoas e comunidades.

🛠️ Tecnologias utilizadas

HTML5

CSS3

🌎 Impacto social

Acreditamos que a tecnologia pode ir além das telas: ela pode aproximar pessoas, ampliar oportunidades e contribuir para uma sociedade mais conectada e solidária.

📚 Projeto acadêmico

Desenvolvido como atividade acadêmica para colocar em prática os conhecimentos de desenvolvimento web e explorar o uso da tecnologia em projetos de impacto social.
